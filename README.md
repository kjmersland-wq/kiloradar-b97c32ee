# KiloRadar

Redesign KiloRadar (kiloradar.com) into a modern, inviting consumer web app for tracking shrinkflation, unit prices, and cheapest grocery chains.

Core features to keep and make more prominent:

- Unit price / shrinkflation calculator (old vs new size + price)

- Product database with barcode search

- Weekly/monthly/yearly cheapest store ranking per country (show which chains are cheapest on a typical household basket)

- Multi-country support with local currencies and chains

Design goals:

- Modern premium dark theme (deep navy/near-black, soft whites, green for savings, red/amber for shrinkflation)

- Strong visual hierarchy and plenty of whitespace

- Make the "cheapest chain this week/month/year" section prominent and visually clear (ranking cards with big numbers)

- App-like feel with rounded cards, subtle shadows, smooth transitions

- Hero with strong before/after example + big percentage

- Clean product cards and store comparison

- Mobile-first and responsive

- Friendly but trustworthy tone

- Tailwind CSS + React

Make the store ranking and unit-price insights feel central and delightful, not buried. Prioritize clarity for everyday shoppers.
